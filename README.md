# Code for this tutorial:
https://home.et.utwente.nl/slootenvanf/2026/08/28/distance-sensor-pico-micropython/

```blink.py - standard Blink example
buzzer.py - Buzzer test
display.py - Display test
hcsr04.py - Driver* for the Ultrasonic sensor
main.py - Main test script, displays measured sensor values on the display
ssd1306.py - Display driver* for the I2C OLED display 
ultrasonic_sensor_warning.py - Full example for the final part of the tutorial
```
\* Drivers are based on these:
[display](https://github.com/micropython/micropython-lib/tree/master/micropython/drivers/display/ssd1306)
[ultrasonic sensor](https://github.com/rsc1975/micropython-hcsr04)
